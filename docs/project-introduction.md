# 留白成蓝

面向文旅场景的开源非遗互动展陈平台

让游客走进一门手艺，带走一件自己的作品。

一朵花为什么会留在蓝里？留白成蓝把这个问题变成可以亲手回答的旅行体验。游客选择一个意象，观察花版、白浆与棉布的关系，自己施浆、浸染、揭纹，再为成布命名。刮过与漏下的每一处，都参与最后的蓝白。

平台以蓝印花布为完整工艺内核，提供五种参数纹样、16×16个人刻版、三种排布、留桥和四套蓝色配方。游客的实际施浆数据贯穿平面成布、立体验布、生活应用与纪念卡；领取后的花版可以继续编辑，让旅行纪念成为下一次创作的起点。

场馆把一场展览整理为可交换的展陈包：故事、花版、路径、可调控件、完成条件与作品卡寄语统一编排，预览后保存并启用。“寻花成布”与“夜色成蓝”分别组织开放创作和夜蓝主题；运营者通过切换展包持续更新内容，复用同一套创作与交付内核。

公共展屏为每位游客建立独立会话，主动结束或空闲倒计时后为下一位铺好新布。作品完成后，本机服务保存24小时领取快照，以二维码连接同网个人设备。展屏继续接待，上一位仍可领取1440×1080纪念卡、保存JSON，再次打开自己的花布。

平台采用原生HTML、CSS、Canvas与WebGL，服务使用Node.js内置HTTP与SQLite，核心资源本地提供。196项自动测试通过；Chrome独立页面已验证部分施浆作品、服务快照与下载JSON一致。可编辑源码、展陈包协议、资源归属与复核记录共同支持场馆更新内容、开发者维护内核，让一次展项建设形成持续换展的基础。
