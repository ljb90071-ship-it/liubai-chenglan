# 部署与现场操作

## 环境与目录

运行环境为Node.js 24或更新的兼容版本，使用内置`node:http`与`node:sqlite`；浏览器需要支持ES模块、Canvas和常见现代DOM接口，WebGL提供立体布面。无需安装npm运行时依赖，也无需外部数据库。项目测试以交付时实际使用版本为准。

在包含`server.mjs`和`package.json`的项目目录运行命令。`site/`为游客与策展界面，`packs/`提供两份内置展陈，`lib/`提供共享协议，`data/`默认保存SQLite。字体和艺术资源随本地站点提供，延伸阅读链接需要互联网。

## 本机体验

```powershell
node --version
node server.mjs --host 127.0.0.1 --port 8769 --data ./data
```

浏览器打开`http://localhost:8769/`，策展入口为`http://localhost:8769/curator.html`。此模式可进行本机展陈与纪念卡下载；未配置可用局域网领取地址时，不生成不可达的手机二维码。

## 展屏创作与手机领取

确认展屏主机在场馆网络中的IPv4地址，以本机实际地址替换下面示例中的`192.168.1.20`：

```powershell
node server.mjs --host 0.0.0.0 --port 8769 --public-url http://192.168.1.20:8769 --data ./data
```

展屏仍通过本机`http://localhost:8769/`打开，保证运营写入来自回环地址；手机连接同一网络，通过二维码中的局域网地址领取。`0.0.0.0`是监听设置，不能作为手机访问地址。网络需允许手机到展屏主机8769端口的连接，访客Wi-Fi的设备隔离可能阻断访问。防火墙或网络设置由场馆按其管理流程配置。

服务启动时核对公共地址是否为HTTP、端口与服务一致、地址匹配本机非回环网卡（当前使用网卡IP，不支持自定义域名）、监听允许访问。启动输出和`GET /api/bootstrap`中的`claimReady`表示配置是否符合当前拓扑；实际手机联网还需要现场打开一次地址确认。当前服务不验证外部HTTPS反向代理，因此不将代理地址作为已支持的领取部署方式。

## 开展流程

1. 在策展工作台选择“寻花成布”或“夜色成蓝”，编辑展陈文字、入场花版、路径和完成条件。
2. 打开游客预览，检查完整任务。保存版本后再“启用展陈”；未保存或预览状态不会替换正在展出的内容。
3. 在展屏点击开始，选意、制作、揭纹，检查纪念卡，然后生成领取二维码。
4. 手机扫码，下载纪念卡或可编辑花版；点击继续制作后进入`?mode=personal`个人工坊。
5. 展屏点击“下一位”。空闲超过展包阈值时先显示倒计时，游客可以继续；倒计时结束开始新会话。

主题切换在下一次开始体验时读取当前启用展包。当前游客和已保存快照保留入场版本的故事与参数。个人工坊的草稿与收藏属于当前设备和站点地址，更换地址或清理浏览器数据后不会自动同步。

## 接口与权限

| 接口 | 方法 | 用途与访问范围 |
|---|---|---|
| `/api/bootstrap` | GET | 当前展包与领取配置；仅本机响应附运营CSRF令牌 |
| `/api/exhibit` | GET | 当前启用展包 |
| `/api/packs` | GET／POST | 本机读取列表／保存展包，POST体为`{pack}` |
| `/api/activate` | POST | 本机启用展包最近保存版本，体为`{id}` |
| `/api/artworks` | POST | 本机创建规范化作品快照，体为`{envelope}` |
| `/api/artworks/{token}` | GET | 持令牌读取24小时内作品 |

运营POST要求`application/json`、`X-Liubai-Token`及同源浏览器请求；请求体最大256KiB。领取令牌为随机256位值，作为拥有即领取的地址，应仅展示给对应游客。服务无场馆账户、远程策展权限或多人云后台。

## 数据保留与停机

作品快照默认有效24小时，读取时即时检查期限；服务每分钟清理一次，并在重启时清理。过期作品内容从`artworks`删除，到期令牌哈希标记最多再保留7天以返回明确的过期状态。二维码仍指向运行中的本机服务，关闭主机或离开可达网络后不能领取；已下载PNG和JSON继续留在游客设备。

按Ctrl+C正常停止服务。需要备份策展版本时先导出展包JSON；需要备份数据库时优先正常停止，再复制数据目录。运行中SQLite使用WAL，不能只复制主数据库文件并据此认定已取得完整备份。恢复同一数据目录后，未到期快照继续可读，但手机访问地址须保持可达。

## 故障处理与验收

| 现象 | 检查与处理 |
|---|---|
| 显示“手机领取尚未连接” | 检查实际LAN地址、监听与端口；重新启动后读取就绪状态 |
| 手机上打不开领取页 | 先用手机访问公共地址；核对同网、Wi-Fi隔离、防火墙和主机运行状态 |
| 策展或提交返回403 | 在展屏主机使用localhost打开；刷新获取当前令牌，不从手机写入 |
| 保存返回409 | 同一版本内容冲突，增加版本号再保存；现有草稿继续保留 |
| 领取显示410／404 | 分别为已过期／未知地址；回展屏重新操作或使用已下载文件 |
| 浏览器不能保存个人草稿 | 下载JSON；之后在个人工坊导入，避免依赖当前存储权限 |

开展前执行`npm test`，并实际检查：一次部分施浆作品的扫码领取与继续编辑、两位游客的完整切换、空闲倒计时取消与归零、网络失联重试、目标屏幕与真实手机。测试结果以项目README指向的验收日志为准。

## 平面模式

低性能终端可打开`/?renderer=canvas`，不申请WebGL上下文，使用现有Canvas平面预览，创作、施浆、作品交付保持可用。缺少WebGL时亦自动回退。
