The title-ma-outline.svg uses intact Ma Shan Zheng glyph contours, with project
layout offsets and small rotations. It is not a newly authored typeface. Keep this
notice and OFL-mashanzheng.txt when redistributing the derived glyph artwork.

Display subsets cover the recorded short titles only. Body subsets cover the
recorded site text and printable ASCII. User-created names and later content may
use the declared system CJK fallback. Cormorant additionally includes editorial
punctuation. These static fonts have no advertised variable axes.

v0.6 coverage update — 2026-10-26
The existing v0.5 font subsets were retained and merged with only newly needed
glyphs fetched from the same official Google Fonts families and static weights.
fontTools 4.63.0 merged the subsets and wrote WOFF2. Empty shaping-table shells
with no ScriptList were removed before merging; no active shaping rules were
removed. Decomposed glyph contours and horizontal advance/bearing values were
compared against the original subsets for every requested non-space character.
The exact character sets, additional sources, download hashes and resulting font
hashes are recorded in SOURCE.json. All original copyright notices and OFL 1.1
licenses still apply.
